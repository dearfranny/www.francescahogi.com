## How to ship a change (do this for her every time)
1. `git pull` first so we start from the latest version.
2. Make the change.
3. Run `npm run build`. Fix anything that fails before going further.
4. Show her a short plain-English summary and ask "Ready to push it live?"
5. On yes: commit with a clear message and `git push`. Vercel deploys automatically from main.
6. Tell her it will be live in about a minute.

## How she likes to work
She batches changes: collect everything she wants, then build once. Don't push half-done work.
